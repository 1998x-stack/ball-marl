## Game mechanics provenance
Game-specific values in this documentation are **candidate engineering parameters**, not reverse-engineered official facts. Calibration must record build, mode, direct evidence, measurement uncertainty and parameter version. Do not substitute community guide descriptions for authoritative numeric physics constants.

## Reproduction checklist
Pin dependency versions and bibliographic links at implementation time. Validate publication identifiers before formal citation in a paper. Track whether each conclusion comes from a peer-reviewed result, open-source implementation, declared simulator model or independent empirical measurement.
